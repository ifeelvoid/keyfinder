# Product briefs

Briefs record product intent before multi-file work begins. Each filed brief lives in
`NNNN-slug/brief.md` with a factual `ledger.md` once execution starts. Drafts in
`_drafts/` are intentionally unnumbered; filing is the explicit decision to start work.

Private catalog and project names are replaced with song IDs (T01…, S81) and private
folders with placeholders (`<music-root>`, `<cloud-drive>`); the mapping stays local.
